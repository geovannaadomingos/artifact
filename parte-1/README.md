# Part 1 – Theoretical Questions

This directory contains the theoretical foundation and conceptual architectural answers required in the first part of the technical challenge.

## Content

The detailed answers are available in:
- [`part_1_theoretical_questions_answers.pdf`](./part_1_theoretical_questions_answers.pdf)

## Key Topics Covered

1. **ReactJS & Next.js: Rendering Strategies**
   - In-depth comparative analysis between *Client-Side Rendering* (CSR), *Server-Side Rendering* (SSR), and *Static Site Generation* (SSG).
   - Evaluation of advantages, disadvantages, impacts on SEO, TTFB, FCP, and recommended production scenarios.

2. **Backend: Architectural Models & Concepts**
   - Primary backend architecture models for modern web applications (Traditional Monolith, Microservices, Serverless/Edge Functions, and Backend-for-Frontend - BFF).
   - Technical and critical assessment of **tRPC**, weighing security, end-to-end static type safety, organizational scalability, and multi-client trade-offs.
